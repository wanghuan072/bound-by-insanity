# Current responsive plan

Only max-width 1024px and 768px. Keep the existing classes and design tokens. Above 1024px use the 1400px max container, complete left-column player/body/video and 360px task rail separated by 32px. At 1024px use hamburger navigation, a 260px rail and 24px gap; Header height is measured at runtime. Rail top is Header plus 16px and bottom is bounded by game-layout; tall rail follows both scroll directions without internal scrollbars. At 768px use 16px gutters and document flow: player/status, rich independent body, video, then the two topic links. Characters images stack; tables stay within their wrapper. Menu and Footer contain the same three primary links. Images retain native dimensions and contain geometry.
