# Active data flow

main-game.json → strict Game validator → published main loader → homepage cover, player, introduction, independent body, FAQ, TDK and structured data. The iframe address exists only in player.iframeSrc. Its first-version runtime status remains provisional; safe loading or safe refusal does not establish full game playability.

characters.json and endings.json → strict topic validator → topic routes, accurate task covers, related topic links and JSON-LD. Static TDK stays in seo/tdk.js. No Guide or additional-game records are imported.

content-map.json and route-registry.json → public-scope validation → generated-site.json → shared Header, mobile menu, Footer and route inventory. main-game, topics, Legal, current visible cards, navigation and used media hashes → content fingerprints → page-lastmod.json → sitemap. Unchanged visible content retains dates.

Claims, main-game keyword/video queries, timed observations, three active page blueprints and twelve adopted media records remain internal. publicationEvidence validates the current three content records and their evidence/media tasks without removed Guide files. Historical candidate and Guide materials are in reports/archive, never public or build dependencies.
