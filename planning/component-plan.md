# Current component responsibilities

SiteHeader and SiteFooter consume one generated navigation configuration. SiteLink performs complete document navigation. BoundaryRail follows real scrolling between Header and parent boundaries. HomePage renders GamePlayer, the seven-section independent body, a direct lazy privacy-enhanced YouTube embed, and two accurate main-game topic cards. TopicPage renders Characters and Endings with their own JSON content, task covers, breadcrumbs and related topic links. LegalPage renders the five root policy pages without forms.

ContentBlocks renders validated plain structured blocks; LocalImage preserves actual image identity and contain geometry. FullscreenControls uses two visibly distinct SVGs. StructuredData and metadata derive only current data. There is no Guide list/detail, Guide TOC, additional-game list/detail, comments or advertising component.
